# UC-012 Get Project

## Goal

Retrieve a project.

## Actor

User

## Preconditions

- The user is authenticated.

## Main Flow

1. The user requests a project.
2. The system retrieves the project.
3. The system returns the project.

## Alternative Flows

### AF-2.1 Project does not exist

- **2.a.** The requested project does not exist.
- **2.b.** The system informs the user that the project does not exist.

## Postconditions

_None._

## Business Rules

_None._
