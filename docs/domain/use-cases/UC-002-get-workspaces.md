# UC-002 Get Workspaces

## Goal

Retrieve all workspaces.

## Actor

User

## Preconditions

- The user is authenticated.

## Main Flow

1. The user requests the list of workspaces.
2. The system retrieves the available workspaces.
3. The system returns the workspace list.

## Alternative Flows

_None._

## Postconditions

- The workspace list has been returned.

## Business Rules

_None._
